# MediaHub

Локальная медиатека на Flask для фото, фильмов и сериалов. Она объединяет локальные каталоги и FTP/FTPS, индексирует метаданные в SQLite, сохраняет переносимые `.mediahub.json` рядом с контентом и автоматически готовит браузерный видеопоток через FFmpeg.

## Быстрый запуск через Docker

```powershell
docker compose up --build -d
```

Откройте `http://localhost:8080`, задайте пароль администратора и подключите источник. Каталог `./media` контейнера доступен приложению как `/media`; другие каталоги хоста можно добавить в `compose.yaml` отдельными томами.

## Запуск на Windows

Установите Python 3.11+ и FFmpeg. FFmpeg можно установить через `winget install Gyan.FFmpeg`. Затем выполните:

```powershell
.\scripts\start-windows.ps1
```

Скрипт создаёт окружение и устанавливает зависимости при первом запуске. После обновления приложения запустите его один раз с параметром `-Install`.

Для автоматической проверки и установки всех обязательных компонентов используйте:

```powershell
.\scripts\check-dependencies.ps1
```

Сценарий проверяет версию Windows и PowerShell, архитектуру, Python, виртуальное окружение, Python-пакеты, FFmpeg, ffprobe, браузерный HLS-плеер и порт 8080. FFmpeg при необходимости устанавливается локально в `.tools`, поэтому права администратора не нужны.

Доступные режимы:

```powershell
# Только проверка без изменений
.\scripts\check-dependencies.ps1 -CheckOnly

# Повторная установка Python-пакетов
.\scripts\check-dependencies.ps1 -Repair

# Проверка, установка и немедленный запуск
.\scripts\check-dependencies.ps1 -StartMediaHub
```

Сценарий совместим с Windows PowerShell 3.0–5.1 и рассчитан на 64-битные Windows 8.1, 10 и 11. На Windows 8.0 он выполняет диагностику и попытку установки, но Python 3.11 официально поддерживает Windows начиная с 8.1.

Приложение слушает порт 8080 на всех сетевых интерфейсах. Адрес для другого устройства обычно имеет вид `http://192.168.1.20:8080`.

## Структура медиатеки

Каждый источник содержит каталоги `video` и `photo`. Папка первого уровня считается отдельным объектом, а вложенность внутри неё отображается как сезоны, серии или части альбома.

```text
video/
  Пространство/
    .mediahub.json
    Сезон 1/
      Серия 01.mkv
      Серия 01.srt
photo/
  Отпуск 2026/
    .mediahub.json
    День 1/
      IMG_0001.heic
```

Файлы непосредственно в `video` или `photo` группируются в объект «Без категории». При первом сканировании приложение создаёт sidecar-файлы, поэтому источнику требуются права записи.

## Настройки окружения

- `MEDIAHUB_SECRET_KEY` — постоянный секрет приложения. Если переменная не задана, ключ создаётся в `instance/secret_key`.
- `MEDIAHUB_FFMPEG` и `MEDIAHUB_FFPROBE` — пути к исполняемым файлам FFmpeg.
- `MEDIAHUB_HOST` и `MEDIAHUB_PORT` — адрес и порт Waitress.
- `MEDIAHUB_CACHE_MAX_GB` — максимальный размер кэша, по умолчанию 50 ГБ.
- `MEDIAHUB_MAX_FILE_GB` — максимальный размер одного загружаемого файла, по умолчанию 500 ГБ.

Просмотр доступен без входа. Подключение источников, загрузка, создание папок и изменение метаданных требуют пароля администратора. Приложение рассчитано на доверенную домашнюю сеть и не должно публиковаться напрямую в интернет.
